## 数据结构记录

### 线性表

* 时间复杂度

| 方式/时间复杂度/表 | 顺序表 | 链表      | 静态链表  |
| ------------------ | ------ | --------- | --------- |
| 按位查找           | o(1)   | o(n)      | o(n)      |
| 按值查找           | o(n)   | o(n)      | o(n)      |
| 插入               | o(n)   | o(n)+o(1) | o(n)+o(1) |
| 删除               | o(n)   | o(n)+o(1) | o(n)+o(1) |

* 卡特兰数

  $\frac{1}{n+1}C^{n}_{2n}$

* 树

  * m叉树某一层最多节点 $m^{i-1}$

  * m叉树高h总结点最多$\frac{m^{h}-1}{m-1}$

  * 节点个数等于分支个数+1 $n_0+n_1+n_2 = 1n_1+2n_2+1$

  * 完全二叉树总结点n 叶子节点$\frac n2 或者 \frac {n+1} 2$
  
* 完全图 边

  $\frac {n(n-1)} 2$

* 复杂度

  * 邻接矩阵 $O(|V|^2)$

  * 邻接表 无向图$O(|v|+|2E|)$  有向图 $O(|v|+|E|)$ 

  * BFS 邻接表 $O(|v|+|E|)$  临界矩阵 $O(|V|^2)$ 辅助队列

  * DFS 邻接表 $O(|v|+|E|)$  临界矩阵 $O(|V|^2)$ 
  * 最小生成树 Prim   邻接矩阵$O(|V|^2)$  边稠密
  * 最小生成树 Kruskal 邻接表$|E|log_{2}{|E|}$ 边少点多
  * 单源最短路径 BFS 权值为1 无负数 邻接表 $O(|v|+|E|)$  临界矩阵 $O(|V|^2)$
  * 单源最短路径 Dijkstra 无负数 邻接矩阵$O(|V|^2)$
  * 各点最短路径 Floyd 邻接矩阵$O(|V|^3)$
  * 拓扑排序 邻接表 $O(|v|+|E|)$  临界矩阵 $O(|V|^2)$
  * 关键路径 邻接表 $O(|v|+|E|)$  临界矩阵 $O(|V|^2)$
  * 折半查找 树高 $\lceil log_2{(n+1)}\rceil$ 关键字有序顺序表
